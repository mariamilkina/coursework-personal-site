## Что мы изучали на курсе

В рамках курса я познакомилась с основными инструментами разработки, автоматизации и публикации веб-проектов:

- работой с Git и GitHub;
- использованием SSH для подключения к удалённым репозиториям;
- контейнеризацией приложений с помощью Docker;
- настройкой CI/CD с использованием GitHub Actions;
- работой с ветками `main` и `develop`;
- публикацией и развёртыванием приложений;
- мониторингом с помощью Prometheus и Node Exporter;
- визуализацией метрик в Grafana;
- созданием документации и статических сайтов с помощью Markdown и MkDocs;
- публикацией сайта через GitHub Pages.

## Лабораторные работы

- **Лабораторная работа №1 — Docker.** Основы контейнеризации, создание Docker-образов и запуск контейнеров.
- **Лабораторная работа №2 — CI/CD.** Настройка GitHub Actions, работа с ветками и автоматизация процессов развёртывания.
- **Лабораторная работа №3 — Monitoring.** Настройка Prometheus, Node Exporter и Grafana для мониторинга системы.
